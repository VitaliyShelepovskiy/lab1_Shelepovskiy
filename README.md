# Конвертер систем счисления с архитектурой MVC

## Описание проекта

Приложение с графическим интерфейсом на JavaFX, которое преобразует числа из различных систем счисления (2, 8, 10, 16) в ASCII-символы и двоичный код. Реализовано с использованием архитектурного паттерна Model-View-Controller (MVC).

## Функциональность

- **Выбор системы счисления** (2, 8, 10 или 16) через выпадающий список
- **Ввод числа** в выбранной системе счисления
- **Конвертация в ASCII-символ** – числовой код преобразуется в соответствующий символ
- **Конвертация в двоичный код** – отображение бинарного представления числа
- **Обработка ошибок** – корректная работа с числами в разных системах счисления

## Пример использования

| Входные данные | Результат |
|----------------|-----------|
| Система: 10, Число: 65 | ASCII: `A`, Binary: `1000001` |
| Система: 16, Число: 41 | ASCII: `A`, Binary: `1000001` |
| Система: 2, Число: 1000001 | ASCII: `A`, Binary: `1000001` |
| Система: 8, Число: 101 | ASCII: `A`, Binary: `1000001` |
